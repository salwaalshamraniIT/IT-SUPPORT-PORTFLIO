## Project 01 — Cisco Network Configuration & Troubleshooting

### Overview

This project demonstrates a Cisco network configuration using Cisco Packet Tracer.

The network includes routers, switches, servers, and a client device configured to demonstrate SSH, NTP, Syslog, and IP addressing.

### Technologies

- Cisco Packet Tracer
- Cisco Routers
- Cisco Switches
- SSH
- NTP
- Syslog
- IP Addressing
### Troubleshooting
- Issue: Encountered access restriction (% Bad secrets) during privileged mode authentication on Router R1.
- Resolution: Successfully resolved configuration access management via device environment diagnostics.
- Verification: Verified OSPF protocol states (LOADING to FULL) and confirmed active Syslog host logging.
