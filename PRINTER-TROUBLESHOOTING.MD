# Printer Troubleshooting

## Problem
A user is unable to print a document.

## Objective
Identify the cause of the printing issue and restore normal printing functionality.

## Troubleshooting Steps
1. Check the printer status in Windows.
2. Check the print queue for pending or stuck documents.
3. Verify that the correct printer is selected as the default printer.
4. Restart the Print Spooler service if necessary.
5. Send a test page to verify that printing is working.

## Tools Used
- Windows Settings
- Printers & scanners
- Print Queue
- Print Spooler

## Result
The printer was tested successfully after troubleshooting.
